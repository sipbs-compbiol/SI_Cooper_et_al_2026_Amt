# README.md SI_Cooper_et_al_2026_Amt

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23365692.svg)](https://doi.org/10.5281/zenodo.23365692)

This repository describes supplementary statistical anakysis for the Cooper _et al._ (2026) manuscript "Structural and functional basis of lipid-associated, electrogenic ammonium transport by the Rhesus-family protein NeRh50 in _Nitrosomonas europaea_."

The analysis proceeds from the data file `NeRh50_CryoEM_raw_data complete.xlsx` provided by Arnaud Javelle (2026-10-08). This is a workbook comprising six worksheets, one per subfigure dataset. This data was exported to separate `.csv` format files, one per subfigure:

- `fig_4c.csv`
- `fig_5a.csv`
- `fig_5b.csv`
- `fig_6b.csv`
- `fig_6d.csv`
- `fig_6f.csv`

This data is presented in the `assets/data` folder.
